# مراحل التطوير
1. فتح المشروع وتشغيل وضع العرض.
2. تصميم الواجهة حسب اختيارات صاحب المشروع.
3. إنشاء Supabase وتشغيل SQL وربط متغيرات البيئة.
4. اختبار الحسابات والمشاريع والمرفقات والتعليقات.
5. استعادة كلمة المرور وحذف الحساب والبلاغات والإدارة وتحديد المعدلات.
6. المتابعة والإشعارات والتحديات الفعلية عند الحاجة.
7. اختبار أمان وخصوصية وتشغيل تجريبي مغلق.
8. نشر عام بعد معالجة نقاط النقص.
9. السوق والمدفوعات مشروع توسعة منفصل.
