# خطة النشر لاحقًا

هذه خطوات عمل مقترحة وليست دليلًا على أن النشر تم.
1. إتمام الاختبارات ومعالجة كل خطأ.
2. تحديث الاعتمادات إلى إصدارات مدعومة وآمنة ومراجعة lockfile.
3. رفع الكود إلى مستودع GitHub خاص أولًا مع استثناء .env.local.
4. إنشاء مشروع Vercel واستيراد المستودع.
5. إضافة متغيرَي البيئة العامين في إعدادات الاستضافة.
6. تنفيذ Build والتحقق من السجلات.
7. إضافة عنوان الإنتاج الصحيح إلى إعدادات Auth في Supabase.
8. مراجعة RLS والتخزين والنسخ الاحتياطية والخصوصية والإشراف ومكافحة إساءة الاستخدام.
9. اختبار محدود بدعوات قبل أي إطلاق عام.
لا تنشر مفاتيح إدارية. لا تفترض أن استخدام الخطة المجانية يلغي حدود الخدمات أو تكلفة النمو.
