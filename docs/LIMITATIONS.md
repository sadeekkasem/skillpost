# حدود النسخة

منفذ بالكود، لكنه لم يخضع لاختبار تشغيل هنا:
- الواجهة العربية المتجاوبة، قائمة المشاريع، بحث في أحدث 100 مشروع.
- وضع أمثلة دون قاعدة بيانات.
- التسجيل والدخول والخروج، تعديل الاسم والنبذة.
- نشر مشروع ومرفق واحد اختياري، عرض وتحميل المرفقات برابط مؤقت للمسجلين.
- تعليقات، إعجاب واحد لكل حساب لكل مشروع، حذف المشروع للمالك.
- صفحة ملف شخصي وصفحة تعليمات وأفكار تحديات.

غير منفذ:
- متابعة المستخدمين والإشعارات والرسائل والسوق والمدفوعات.
- تحديات حقيقية أو تقييمات أو شهادات مهارات.
- إدارة المحتوى والبلاغات والحظر ومكافحة السبام وتحديد المعدلات.
- استعادة كلمة المرور وحذف الحساب ذاتيًا وتغيير البريد.
- تعديل المشاريع وتعليقات المستخدم من الواجهة، صور الملف الشخصي.
- pagination وإحصاءات واختبارات آلية.
- فحص الملفات بمضاد فيروسات. تقييد الامتدادات وMIME ليس ضمان أمان للمحتوى.

مسودات الشروط والخصوصية غير جاهزة قانونيًا للنشر.
تنزيل الملفات متاح لكل مستخدم مسجل، وليس لصاحب الملف فقط؛ المحتوى العام ليس مخزنًا لبيانات حساسة.
الحذف المتسلسل في الجداول لا ينظف storage تلقائيًا في كل مسار؛ حذف المشروع من الواجهة يحاول حذف مرفقاته أولًا، ويحتاج المشروع لاحقًا مهمة تنظيف دورية.
الحزمة غير مدققة أمنيًا أو مختبرة بالبناء. لا تعتبرها جاهزة للنشر العام.
